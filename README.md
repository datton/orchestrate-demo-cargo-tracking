# cargo-tracking.demo.orchestrate.ca

Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript.

## Pages
index.html (explainer on ocean freight cargo tracking) and dashboard.html (demo dashboard). Static HTML/CSS/JS, no build step, no backend. **All readings on the dashboard are simulated**; they are generated in the browser and clearly labelled as such. No real vessels, shipments or carriers.
